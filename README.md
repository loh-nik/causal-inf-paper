# Code for: Quantitative Comparison of Causal Inference Methods for Climate Tipping Points

This project contains the implementation for evaluations of three causal inference methods, the PCMCI method by Runge et al. [1], the Liang-Kleeman Information Flow (LKIF) by Liang [2] and the Granger Causality for State Space Models (GCSS) [3]. For applied experiments, we provide a pipeline script for causal inference of multivariate time series. The user can configure data sources, preprocessing options and the causal methods used for causal analysis.
Options also include analysis of spatially resolved data (in .npy format), and causal stationarity (a sliding time window approach). Results are visualized in different types of plots, including graphs and maps.

We provide a custom aggregation of neXtSIM sea ice reanalysis data by the E.U. Copernicus Marine Service Information [4] and we're grateful to have used (and also provide here) several AMOC data series as aggregated by Högner et al. [5].

# Setup

It's recommended to start by installing GNU Octave, which is used to run the GCSS algorithm, and adding it to the PATH (see https://pypi.org/project/oct2py/).

After that, install the full-env.yaml (into a conda virtual environment), and install the tigramite package manually, following https://github.com/jakobrunge/tigramite/.

# Usage

The script Evaluation.py was used to evaluate the methods on synthetic data, one can entirely reproduce the corresponding results from the main method.

The Pipeline.py file contains the main pipeline, which can be run from the command line with several arguments, run Pipeline.py -h for a list and description of arguments. The data used in the paper is provided in the file DataSheet.csv.

Spatial analysis requires an npy array with dimensions x,y,time. Further, latitude and longitude needs to be provided to plot the output correctly, in two separate npy files, each with dimensions x,y (for some projections, this might have to be generated by the user first, for some it is provided in common .nc files).
